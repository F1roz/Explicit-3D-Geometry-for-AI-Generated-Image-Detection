# Figures

Paper figures live in `paper/figures/`. Static figures (architecture, study design, workflow,
synthetic cue illustrations) come from `scripts/make_static_figures.py`. Result figures come from
`scripts/generate_figures.py` and are written to `results/<run>/figures/`; copy them into
`paper/figures/` (same file names) to replace the yellow `[xyz]` placeholders. A file named
`<figure>.placeholder` marks a figure that has not been replaced yet.
